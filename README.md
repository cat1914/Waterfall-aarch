
**Waterfall aarch64 Natives**

-------------------------------

This is the **Waterfall Physics's compatibility extension plugin**.
The Waterfall Physics's default natives is building on **x86**.This plugin replaced the default natives to make it compatible with the **aarch64** environment.

-------------------------------

**⚠️⚠️Warning:Don't try to install this plugin on x86 devices.⚠️⚠️**
